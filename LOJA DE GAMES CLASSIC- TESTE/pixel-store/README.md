# Pixel Store

## Descrição
O **Pixel Store** é uma plataforma de e-commerce dedicada a produtos do universo geek, retrô e gaming. O site foi projetado com um tema moderno de dark mode gamer/cyberpunk, oferecendo uma experiência de compra interativa e responsiva.

## Estrutura do Projeto
O projeto é organizado da seguinte forma:

```
pixel-store
├── assets
│   ├── css
│   │   └── styles.css        # Estilos personalizados complementares ao Tailwind CSS
│   └── js
│       └── main.js          # Código JavaScript para funcionalidades interativas
├── index.html                # Página inicial com banner, benefícios, categorias e depoimentos
├── produtos.html             # Página de listagem de produtos com sistema de filtros
├── produto-detalhe.html      # Página de detalhes do produto com informações completas
└── README.md                 # Documentação do projeto
```

## Tecnologias Utilizadas
- **HTML5**: Estruturação do conteúdo.
- **Tailwind CSS**: Framework CSS para estilização responsiva e moderna.
- **JavaScript**: Para interatividade e funcionalidades dinâmicas.

## Funcionalidades
- **Navegação Intuitiva**: Menu de categorias e barra de busca dinâmica.
- **Sistema de Filtros**: Permite aos usuários filtrar produtos por plataforma e faixa de preço.
- **Carrinho de Compras**: Interativo com gaveta lateral que exibe itens adicionados.
- **Responsividade**: Design adaptável a diferentes tamanhos de tela.
- **Depoimentos de Clientes**: Seção para avaliações e feedback de usuários.

## Instruções de Configuração
1. Clone o repositório:
   ```
   git clone <URL_DO_REPOSITORIO>
   ```
2. Navegue até o diretório do projeto:
   ```
   cd pixel-store
   ```
3. Abra o arquivo `index.html` em um navegador para visualizar o site.
